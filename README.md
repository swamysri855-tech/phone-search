# 🔍 Phone Search

ఫోన్‌లో ఉన్న ప్రతిదాన్నీ ఒకే చోట వెతికే Android app:

- 👤 **Contacts**: పేరు లేదా నంబర్‌తో వెతకవచ్చు
- 💬 **Messages (SMS)**: మెసేజ్‌లోని పదాలు, నంబర్, లేదా పంపినవారి పేరుతో వెతకవచ్చు
- 🖼️ **Photos (JPG, PNG…)**, 🎬 **Videos**, 🎵 **Audio**
- 📄 **Documents**: PDF, Word, Excel, TXT…
- 📦 **APK** files, 📁 **అన్ని ఇతర files**
- 🟢 **WhatsApp / WhatsApp Business / Telegram folders**: Gallery లో కనబడని Sent files, Voice notes, Statuses కూడా (All files access ఆన్ చేసి ఉంటే)

## ఎలా వెతకవచ్చు

- **పేరు ప్రకారం**: ఫైల్ పేరు, folder పేరు (ఉదా: `WhatsApp`, `Screenshots`), లేదా రకం (`jpg`, `pdf`) టైప్ చేయండి
- **ఎక్కువ పదాలు**: `whatsapp jpg` అని టైప్ చేస్తే రెండు పదాలూ ఉన్నవి మాత్రమే వస్తాయి
- **తేదీ ప్రకారం**: ఈ రోజు, నిన్న, గత 7/30 రోజులు, ఈ సంవత్సరం, లేదా మీరు ఎంచుకున్న తేదీల మధ్య
- **రకం ప్రకారం**: పైన ఉన్న chips (Contacts, Messages, Photos…)
- **వరుస**: కొత్తవి ముందు, పాతవి ముందు, పేరు A→Z, పెద్ద సైజు ముందు
- ఫలితంపై **tap** చేస్తే తెరుచుకుంటుంది

## 🧹 WhatsApp పాత files తీసేయడం

1. **🧹 WhatsApp పాత files తీసేయి** నొక్కండి
2. **ఏ రకం?** Videos, Audio, Voice notes, Documents, ఫోటోలు, GIFs, Stickers, Statuses
   - మీరు **పంపిన** files (WhatsApp `Sent` folders) ను default గా ముట్టుకోదు. మీకు వచ్చినవి / ఆటోమేటిక్‌గా download అయినవి మాత్రమే
3. **ఎంత పాతవి?** 1 / 3 / 6 నెలలు, 1 / 2 సంవత్సరాల కంటే పాతవి, లేదా 📅 ఒక తేదీకి ముందువి
4. ఏ రకం ఎన్ని files, ఎంత జాగా (GB / MB) అని చూపిస్తుంది
5. **చూసి ఎంచుకో**: అన్నీ ఎంచుకుని, పెద్దవి ముందు చూపిస్తుంది. ఉంచుకోవాలనుకున్నవాటిపై tap చేయండి.
   ఆ తర్వాత **🗑 డిలీట్** → బిన్ (30 రోజులు) లేదా **శాశ్వత డిలీట్** (జాగా వెంటనే ఖాళీ)
- Voice notes లో మీరు పంపినవి, వచ్చినవి ఒకే folder లో ఉంటాయి. వాటిని వేరు చేయలేం
- డిలీట్ చేసినవి WhatsApp chat లో "media unavailable" అని కనిపిస్తాయి. Text messages అలాగే ఉంటాయి

## 📅 తేదీ ప్రకారం

ఈ రోజు, నిన్న, గత 7 / 30 రోజులు, ఈ / గత సంవత్సరం, **1 / 3 / 6 నెలలు, 1 / 2 సంవత్సరాల కంటే పాతవి**,
**ఈ తేదీకి ముందువి**, **ఈ తేదీ తర్వాతవి**, **ఈ తేదీల మధ్య**

## 📁 ఒక Folder లో మాత్రమే వెతకడం

- **📁 Folder ఎంచుకోండి** బటన్ నొక్కి, folders లోకి వెళ్ళి (browse) కావలసిన folder లో **ఇందులో వెతుకు** నొక్కండి
- ⭐ Shortcuts: Camera, Screenshots, WhatsApp Images, WhatsApp Documents, Download, AI_Sorted
- ఆ తర్వాత search, తేదీ, Photos chip, 🤖 AI, తరలించు అన్నీ **ఆ folder (దాని లోపలి folders) లో మాత్రమే** పని చేస్తాయి
- మళ్ళీ ఫోన్ మొత్తం వెతకాలంటే అదే బటన్ నొక్కి **🌐 ఫోన్ మొత్తం** నొక్కండి

## ఎంచుకుని తరలించడం (Multi-select)

- ఏదైనా ఫలితంపై **long-press** చేస్తే selection మొదలవుతుంది. ఆ తర్వాత tap చేస్తూ ఇంకా ఎంచుకోవచ్చు
- క్రింద వచ్చే bar లో:
  - **📂 తరలించు**: ఎంచుకున్న files ని వేరే folder కి move చేస్తుంది (కొత్త folder కూడా తయారు చేయవచ్చు)
  - **📑 Folder కి కాపీ**: అసలు file అక్కడే ఉంచి, కాపీ మాత్రమే వేరే folder లో పెడుతుంది
  - **📤 పంపు**: WhatsApp, Bluetooth, Gmail మొదలైన వాటి ద్వారా పంపవచ్చు
  - **📋 Text కాపీ**: contacts / messages ని text గా కాపీ చేస్తుంది
  - **☑ అన్నీ ఎంచుకో** / **✕** (లేదా Back బటన్) తో selection రద్దు
- File తేదీ మారదు, కాబట్టి తరలించిన తర్వాత కూడా తేదీ ప్రకారం వెతకవచ్చు
- తరలించడానికి **All files access** ఆన్ చేసి ఉండాలి

## 🤖 AI తో ఫోటోలు సర్దడం (Offline)

1. 🖼️ **Photos** chip నొక్కండి (కావాలంటే `whatsapp` లాంటి పదం లేదా 📅 తేదీ కూడా ఎంచుకోండి)
2. పైన ఉన్న **🤖 ఫోటోలను AI తో వేరు చేయి** బటన్ నొక్కండి
   (కొన్ని ఫోటోలే కావాలంటే, long-press చేసి ఎంచుకుని అదే బటన్ నొక్కండి)
3. ఒకటి ఎంచుకోండి:
   - **🌿 మొక్కలు మాత్రమే**: మొక్కలు, ఆకులు, పువ్వులు, పండ్లు, బెరడు, తీగలు, వేర్లు, విత్తనాలు ఉన్న ఫోటోలు మాత్రమే
     `Pictures/AI_Sorted/Plants_Herbs` లోకి. మిగతా ఫోటోలు ఎక్కడివక్కడే ఉంటాయి
   - **🗂️ అన్ని రకాలు**: ప్రతి ఫోటోనూ `Plants_Herbs`, `Food`, `People`, `Animals`, `Documents`, `Vehicles`,
     `Nature`, `Buildings_Places`, `Events`, `Screenshots`, `Others` లోకి
4. **సరిచూసే screen**: AI ఎంచుకున్న ఫోటోలు grid లో వస్తాయి. తప్పుగా వచ్చిన ఫోటోపై **tap** చేస్తే ❌ అవుతుంది (తీసేస్తుంది).
   **Long-press** చేస్తే పెద్దగా చూడవచ్చు
5. **📂 తరలించు** (memory పెరగదు) లేదా **📑 కాపీ** నొక్కండి
   - ఉదాహరణ: `IMG_1234.jpg` → `Plants_Herbs/Leaf_Flower_20261120_054427.jpg`

- AI తన top 5 జవాబులు చూస్తుంది. 60% పైగా నమ్మకం ఉంటేనే మొక్క అని నిర్ణయిస్తుంది
- WhatsApp ఫోటోలను తరలిస్తే WhatsApp chat లో అవి కనబడవు (app ముందే హెచ్చరిస్తుంది)
- ఇంటర్నెట్ అవసరం లేదు, ఫోటోలు ఫోన్ బయటికి వెళ్ళవు
- ఇది సాధారణ రకాలు మాత్రమే గుర్తిస్తుంది. తులసి, వేప లాంటి మొక్కల పేర్లు చెప్పలేదు

## 🗑 డిలీట్ (రీసైకిల్ బిన్ + శాశ్వత డిలీట్)

- ఫలితాలపై **long-press** చేసి ఎంచుకుని, క్రింద bar లో **🗑 డిలీట్** నొక్కండి
  - **బిన్‌కి పంపు**: 30 రోజులు బిన్‌లో ఉంటాయి. పైన ఉన్న **🗑 బిన్** బటన్‌లో **తిరిగి తెచ్చుకోవచ్చు**. 30 రోజుల తర్వాత ఆటోమేటిక్‌గా శాశ్వతంగా పోతాయి
  - **శాశ్వత డిలీట్**: బిన్ లేకుండా నేరుగా పూర్తిగా తొలగిస్తుంది (రెండోసారి నిర్ధారణ అడుగుతుంది)
- వైరస్ అనుమానం ఉన్న ఫైళ్లకు (ముఖ్యంగా APK) **శాశ్వత డిలీట్** వాడండి. APK ని బిన్ నుంచి తిరిగి తెచ్చేటప్పుడు హెచ్చరిక వస్తుంది
- **🗑 బిన్** స్క్రీన్‌లో: తిరిగి తెచ్చుకో / శాశ్వత డిలీట్ / **బిన్ ఖాళీ చేయి**
- Delete కి **All files access** కావాలి

## 📞 ఆఫ్‌లైన్ కాలర్ ID (ట్రూకాలర్ లాగా, ఇంటర్నెట్ లేకుండా)

కాల్ వచ్చినప్పుడు కాంటాక్ట్ పేరు (లేదా మీరు ఇచ్చిన CSV జాబితాలోని పేరు) స్క్రీన్ పైన పెద్దగా చూపిస్తుంది.

1. పైన **📞 కాలర్ ID** బటన్ నొక్కండి
2. వరుసగా: **1️⃣ అనుమతులు** → **2️⃣ ఇతర యాప్‌ల పైన చూపడం** → **3️⃣ కాలర్ ID యాప్‌గా ఎంచుకోండి**
3. తెలియని నంబర్ల పేర్ల కోసం **📥 CSV జాబితా దిగుమతి**: ప్రతి లైన్‌లో `పేరు,నంబర్` (ఉదా: `రాము,9848012345`)
4. +91 / 0 / ఖాళీలు ఎలా ఉన్నా చివరి 10 అంకెలతో సరిపోల్చుతుంది
5. వన్‌ప్లస్ లో: Settings → Battery → ఈ యాప్‌కి **Don't optimize**

- కాల్‌ను ఆపదు, బ్లాక్ చేయదు. పేరు తెలిస్తేనే చూపిస్తుంది. కాల్ ఎత్తినా/కట్ చేసినా బాక్స్ మాయమవుతుంది
- ఇంటర్నెట్ లో ఉన్న ట్రూకాలర్ డేటాబేస్ లేదు కాబట్టి, కాంటాక్ట్స్ / CSV జాబితాలో లేని నంబర్ల పేర్లు తెలియవు

## Install చేయడం

1. ఈ repo లోని **Releases → latest** కి వెళ్లి `PhoneSearch.apk` download చేయండి
2. ఫోన్‌లో ఆ file తెరిచి **Install** నొక్కండి ("Unknown sources" అనుమతి అడిగితే Allow చేయండి)
3. App తెరిచాక Contacts, SMS, Photos అనుమతులు **Allow** చేయండి
4. PDF, APK లాంటి అన్ని files కనబడాలంటే, పసుపు banner లోని బటన్ నొక్కి **All files access** ఆన్ చేయండి

## Build

ప్రతి push కి GitHub Actions (`.github/workflows/build.yml`) APK ని build చేసి `latest` release లో పెడుతుంది.
Local గా build చేయాలంటే: `./gradlew assembleDebug`
